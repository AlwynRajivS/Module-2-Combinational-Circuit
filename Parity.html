Introduction to Parity

Parity is a simple error-detection method. A parity generator at the sender adds one extra parity bit. A parity checker at the receiver tests whether the received word still satisfies the selected parity rule.

Even Parity
Total number of 1s, including P, must be even.
Odd Parity
Total number of 1s, including P, must be odd.
Generator
Creates the required parity bit before transmission.
Checker
Detects a parity mismatch after reception.
Limitation: Simple parity detects every odd number of bit flips, including a single-bit error, but can miss an even number of bit flips. It detects errors; it does not correct them.

3-Bit Parity Generator

Even parity bit Pₑ = A ⊕ B ⊕ C = Σm(1,2,4,7)
Odd parity bit Pₒ = (A ⊕ B ⊕ C)̅ = Σm(0,3,5,6)
The K-map contains an alternating checkerboard pattern, so adjacent 1s cannot be grouped conventionally. Recognizing the XOR pattern gives the compact expression.

4-Bit Parity Checker

Even-parity error flag EEC = A ⊕ B ⊕ C ⊕ D
Odd-parity error flag OEC = (A ⊕ B ⊕ C ⊕ D)̅

For even parity, EEC=0 means valid and EEC=1 indicates a detected error. For odd parity, OEC=0 means valid and OEC=1 indicates a detected error.

Applications

Serial Communication
UART-style frames may use a parity bit for basic error detection.
Memory Systems
Parity can detect corruption in stored or transferred data words.
Computer Buses
Provides a lightweight integrity check for digital transfers.
Communication Links
Detects many transmission errors caused by noise.
Embedded Systems
Useful where simple, low-gate-count error detection is required.
XOR Logic Learning
Parity demonstrates that XOR is 1 when an odd number of inputs are 1.

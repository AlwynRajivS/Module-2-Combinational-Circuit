🚨 Priority Encoder — the hospital desk, live

handles multiple requests at once

Flip on several requests

In real circuits, more than one input can go active together. A priority encoder always reports the highest-priority one — I3 outranks I2, which outranks I1, then I0. Toggle a few switches and watch it decide.

I3 — Criticalhighest
I2 — Urgent
I1 — Routine
I0 — Minorlowest

Decision

No request active.
Output stays idle.
Analogy: If three patients arrive together, the desk still calls only the most critical one first — the others wait their turn, unrepresented in this moment's code.

📬 Memory Address Decoder — the postal route, live

3-to-8 line, scaled up

Slide the address

A processor puts an address on its address bus. Address-decoding logic finds the one memory bank that should respond — everyone else on the bus ignores it.

000 → Bank 0

Memory bank

Analogy: address code = house number, decoder = postal worker, activated bank = the one house that opens its door.

🔢 BCD → 7-Segment Decoder — drawing digits, live

4 bits in, 7 segments out

Pick a digit

Tell the decoder "draw a 5" and it lights only the strokes a real 5 needs — exactly like an artist who knows which lines to draw and which to leave blank.

BCD code: 0000
Only the required segments are switched ON. Everything else stays dark — nothing is "guessed."

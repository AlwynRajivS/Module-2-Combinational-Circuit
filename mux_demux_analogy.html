Basic Multiplexer — Selector switch: Four data lines sit ready, but only one at a time is allowed onto the shared output wire. A 2-bit select code decides which one gets through. Digital idea: many inputs, one chosen path.

🧩 Multiplexer vs Demultiplexer — side by side

PropertyMultiplexerDemultiplexer
Question it answers"Which input reaches the output?""Which output should this input reach?"
Input : Output count2ⁿ data inputs → 1 output1 input → 2ⁿ outputs
Select lines neededn lines choose among 2ⁿ inputsn lines choose among 2ⁿ outputs
Direction of flowMany → One (data selector)One → Many (data distributor)
Real-world twinExpo calling one ticket to the passMail sorter dropping a letter in one bin
Classic ICs74151 (8-to-1), 74153 (dual 4-to-1)74138 (used as 1-to-8), 74139 (dual 1-to-4)
Note the mirror: a Decoder is really a Demultiplexer whose data input is tied permanently "on," and a Multiplexer is what an Encoder would need if the inputs carried real data instead of just a position. Same select-line logic, different job on the data line.

Why share one line?

Instead of routing 8 sensor wires all the way to a single analog-to-digital converter, an 8-to-1 multiplexer lets one converter read any sensor on demand — far less wiring for the same information.

A single processor pin can control 8 different devices one at a time by pairing a demultiplexer with a 3-bit address — no need for 8 separate control wires all the way back to the processor.

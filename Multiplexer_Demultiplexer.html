Introduction

Multiplexer & Demultiplexer

Multiplexer — Data Selector

A MUX is a combinational circuit with 2ⁿ data inputs, n select lines and one output. The select code determines which input reaches the output.

Many inputs → select one → one output.

Demultiplexer — Data Distributor

A DEMUX is a combinational circuit with one data input, n select lines and 2ⁿ outputs. The select code determines which output receives the input.

One input → select destination → many possible outputs.

Applications

Data routing, parallel-to-serial selection, communication channel selection, sensor/ADC input selection, processor and memory buses, controlled signal distribution and digital switching.

🧠 Deriving Y1

Look at the MSB, Y1. Which winners produce Y1 = 1?

D3 wins → 11 → Y1 = 1
D2 wins → 10 → Y1 = 1
D1 wins → 01 → Y1 = 0
D0 wins → 00 → Y1 = 0

Therefore Y1 is 1 whenever D3 OR D2 is the winning input.

Y1 = D3 + D2
Memory: “Is the winner D3 or D2?”

💡 Deriving Y0

Now look at the LSB, Y0. Which winners produce Y0 = 1?

D3 wins → 11 → Y0 = 1
D2 wins → 10 → Y0 = 0
D1 wins → 01 → Y0 = 1
D0 wins → 00 → Y0 = 0

D3 can directly make Y0 = 1. D1 can make Y0 = 1 only when D2 is OFF.

Y0 = D3 + D2' D1
Why D2'? If D2 = 1 and D1 = 1, D2 wins because D2 has higher priority. Therefore D1 is allowed to contribute only when D2 = 0.

Decoder

A combinational circuit that converts n binary inputs into a maximum of 2ⁿ outputs. In an active-high decoder, one output is selected for each input code.

n inputs → 2ⁿ outputs
Applications
  • Memory/address decoding
  • Chip and device selection
  • Instruction decoding
  • Demultiplexing/control generation

Encoder

The reverse function of a decoder. A conventional encoder converts one active line among 2ⁿ inputs into an n-bit binary code.

2ⁿ inputs → n outputs
Applications
  • Keyboard/keypad encoding
  • Octal-to-binary conversion
  • Interrupt-source encoding
  • Data transmission
Basic encoders assume one input is HIGH at a time. Multiple simultaneous HIGH inputs require a priority encoder.

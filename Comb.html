Introduction to Combinational Logic Circuits

💡 Definition

A combinational circuit is a digital circuit in which the present output depends only on the present input combination.

🧠 No Memory

It does not store previous input values. Normally, no clock or memory element is required.

⚙️ Building Blocks

AND, OR, NOT, NAND, NOR, XOR and XNOR gates are interconnected to realize required Boolean functions.

🌍 Examples

Adders, subtractors, comparators, code converters, parity circuits, encoders, decoders, multiplexers and demultiplexers.

Steps to Design a Combinational Circuit

Step 1: Understand the problem and required operation.
Step 2: Identify and name all input and output variables.
Step 3: Construct the truth table with all 2ⁿ input combinations.
Step 4: Derive SOP using minterms or POS using maxterms.
Step 5: Simplify using Boolean algebra or Karnaugh Map.
Step 6: Draw the exact logic-gate circuit.
Step 7: Verify the circuit output for all input combinations.

Larger Combinational Circuit Example

Design: F(A,B,C) = A̅B + AC. This example shows how multiple logic gates are connected to realize a larger combinational function. Flip the switches below to see the live signal path.

1. Invert A using a NOT gate to obtain A̅.
2. AND A̅ with B to produce intermediate term X1=A̅B.
3. AND A with C to produce intermediate term X2=AC.
4. OR X1 and X2 to obtain F=A̅B+AC.

Half Adder, Full Adder, Half Subtractor & Full Subtractor

Half Adder

Adds two bits A and B.
Sum=A⊕B
Carry=AB

Full Adder

Adds A, B and Cin.
Sum=A⊕B⊕Cin
Cout=AB+ACin+BCin

Half Subtractor

Subtracts B from A.
Difference=A⊕B
Borrow=A̅B

Full Subtractor

Subtracts B and Bin from A.
Difference=A⊕B⊕Bin

Half circuits introduce one-bit arithmetic. Full circuits include incoming Carry or Borrow, enabling multi-bit arithmetic.

4-Bit Adder, Subtractor & Adder/Subtractor

4-Bit Ripple Carry Adder

Four Full Adders are cascaded. Carry propagates from the LSB stage FA0 toward the MSB stage FA3.

4-Bit Subtractor

Uses 2's complement: complement every B bit using NOT gates and set initial carry C0=1.

Combined Adder/Subtractor

XOR gates condition B using Mode M. M=0 selects addition; M=1 selects subtraction.

Unified Equation

Result=A+(B⊕M)+M
M=0 → A+B
M=1 → A+B̅+1=A−B

Code Converters

Binary to Gray

MSB remains unchanged. Every next Gray bit is XOR of two adjacent binary bits.

Gray to Binary

MSB remains unchanged. Remaining binary bits are obtained using cumulative XOR.

BCD to Excess-3

Add binary 0011 to each valid BCD digit.

Purpose

Converters allow digital systems using different codes to exchange information.

Parity Generator & Checker

Parity is a simple error-detection technique. XOR gates efficiently generate and check parity.

Even Parity

The total number of 1s, including the parity bit, is made even.

Odd Parity

The total number of 1s, including the parity bit, is made odd.

Encoders & Decoders

Encoder

A 2ⁿ-to-n encoder converts one active input line into an n-bit binary code.

Priority Encoder

When multiple inputs are active, the highest-priority input determines the output.

Decoder

An n-to-2ⁿ decoder activates one output corresponding to the binary input combination.

Applications

Memory selection, instruction decoding, display systems and data routing.

Multiplexer & Demultiplexer

Multiplexer

A MUX selects one of many data inputs and connects it to a single output.

4:1 MUX

Four inputs I0–I3 and two select lines S1,S0. The select code determines the output.

Demultiplexer

A DEMUX routes one input signal to one selected output line.

Applications

Data routing, communication systems, bus selection and Boolean function realization.

Function Realization using Multiplexer

Step 1: Write the truth table of the Boolean function.
Step 2: Use variables as MUX select lines.
Step 3: Map each truth-table output to the corresponding MUX data input.
Step 4: The MUX output realizes the function.

Example

F(A,B)=Σm(1,2)=A̅B+AB̅=A⊕B

Using a 4:1 MUX: A,B are select lines. Set I0=0, I1=1, I2=1, I3=0.

Function Realization using Decoder

Step 1: Express the function in canonical SOP form Σm.
Step 2: Connect function variables to decoder inputs.
Step 3: Identify decoder outputs corresponding to required minterms.
Step 4: OR the selected decoder outputs.

Example

F(A,B,C)=Σm(1,3,5,7)

Use a 3-to-8 decoder and connect outputs Y1, Y3, Y5 and Y7 to an OR gate. The simplified result is F=C.
